## Como criar um novo projeto

### Projeto React puro (Vite)
```bash
npm create vite@latest projetos/projetoXX-nome -- --template react-ts
```

### Projeto Next.js
```bash
npx create-next-app@latest projetos/projetoXX-nome --typescript --app
```
