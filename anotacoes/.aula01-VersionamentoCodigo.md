### Diferença entre Git e GitHub

- Registra a historia do projeto
- GitHub hospeda essa historia 
- git é sistema de controle de versões.
    - O git acompanha todas as mudanças feitas nos arquivos de um projeto.
- GitHub é uma plataforma que hospeda repositórios GIt e facilita a colaboração, backup e compartilhamento de projetos e arquivos.
- Repositorio é a pasta de um projeto.

### Ciclo de trabalho do git
1. Edição: Alteração dos arquivos dentro da repositorio
2. Adição: Usamos o comando git add para adicionar todas as alterações na area de stage
3. Ponto historico: Quando finalizamos um conjunto de modificações vamos criar uma descrição para tudo que estiver na area de stage. usamos o comando git commit
4. Publicação: joga para o conteudo da stage para o repositorio remoto
