# Template de Anotação de Aula

Copie este arquivo para `anotacoes/aulaXX-tema.md` ao iniciar uma nova aula.

---

## Como usar

```bash
cp anotacoes/.template.md anotacoes/aula02-meu-tema.md
```

Depois edite os metadados e preencha as seções durante ou após a aula.
